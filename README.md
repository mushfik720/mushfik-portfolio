## ✨ Features

- **Pure HTML5 & CSS3:** No JavaScript, React, Bootstrap, or Tailwind CSS — 100% custom styling.
- **Zero Horizontal (X-Axis) Scrolling:** Engineered with strict container boundaries, adaptive grid fallbacks, and mobile overflow protection.
- **Dark Premium Theme:** Deep cosmic navy/black palette with subtle violet, cyan, and indigo gradient accents.
- **Hero Section:** Features personal portrait (`assets/siam.png`) with an ambient cosmic aura, glassmorphic status ribbon, and floating skill badges.
- **Interactive C Terminal Mockup:** A macOS/VS Code-style terminal window in the About section displaying C source code (`developer_profile.c`), syntax highlighting, line numbers, and console execution output.
- **Semantic Sections:**
  1. **Navbar** — Smooth scrolling with pure CSS mobile drawer navigation (checkbox hack).
  2. **Hero** — Introduction, student credentials, and call-to-action buttons.
  3. **About Me** — Educational context, mindset quote, and quick info grid.
  4. **My Skills** — Realistic progress indicators for HTML5, CSS3, C, and Python.
  5. **Education** — Daffodil International University undergraduate details.
  6. **Learning Journey** — 5-step roadmap of foundational engineering milestones.
  7. **Projects** — Three authentic beginner learning prototypes with tags and repository links.
  8. **My Goals** — Five career aspirations ("Where I Want To Go").
  9. **Contact** — Clean HTML form and direct social channels.
  10. **Footer** — Copyright and back-to-top shortcut.

## 🚀 How to Run Locally

1. Clone or download this repository:
   ```bash
   git clone https://github.com/your-username/portfolio.git
   ```
2. Navigate to the project folder:
   ```bash
   cd portfolio
   ```
3. Open `index.html` directly in your favorite web browser (Chrome, Edge, Firefox, Safari).

---

## 🌐 Deploy to GitHub Pages (Free Hosting)

1. Push this repository to GitHub.
2. Go to **Settings** > **Pages** in your repository.
3. Under **Branch**, select `main` and click **Save**.
4. Your website will be live at:
   ```text
   https://<your-username>.github.io/portfolio/
   ```
